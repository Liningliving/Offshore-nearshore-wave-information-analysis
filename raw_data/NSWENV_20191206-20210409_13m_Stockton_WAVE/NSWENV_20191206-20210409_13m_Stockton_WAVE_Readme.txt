*** DATA ACCESS  
 
Wave buoy data in CSV format with summary plots and statistics can be downloaded from the NSW Sharing and Enabling Environmental Data (SEED) portal. 
 
Download processed data from completed deployments: 
https://datasets.seed.nsw.gov.au/dataset/nsw-nearshore-wave-buoy-parameter-time-series-data-completed-deployments 
 
View and download real-time data from active deployments: 
https://datasets.seed.nsw.gov.au/dataset/nsw-nearshore-wave-buoy-parameter-time-series-data-active-deployments 
 
For advanced users, wave buoy displacements, spectral data and parameter data in netCDF format can be downloaded from the Australian National Wave Archive on the Australian Ocean Data Network (AODN) portal. 
https://catalogue-imos.aodn.org.au/geonetwork/srv/eng/catalog.search#/metadata/2807f3aa-4db0-4924-b64b-354ae8c10b58 
 
Download processed data (advanced formats) from completed deployments: 
https://thredds.aodn.org.au/thredds/catalog/Department_of_Planning_and_Environment-New_South_Wales/WAVE-BUOYS/DELAYED/catalog.html 
 
*** METADATA  
 
Date/time: 
Time at the end of the half-hour buoy displacement measurement period in Australian Eastern Standard Time (AEST) 
 
Coordinate systems: 
Lat,Lon: WGS 1984 - Depth: Australian Height Datum (AHD)
